# Stacked Detection Enhancement Framework

The source code of the paper (Machine-Generated Text Detection Requires Fewer Human-Machine Mixed Texts). The code is built based on [MGTBench](https://github.com/xinleihe/MGTBench).

## Supported Methods
Currently, we support the following methods:
- Metric-based methods:
    - Log-Likelihood [[Ref]](https://arxiv.org/abs/1908.09203);
    - Rank [[Ref]](https://arxiv.org/abs/1906.04043);
    - Log-Rank [[Ref]](https://arxiv.org/abs/2301.11305);
    - Entropy [[Ref]](https://arxiv.org/abs/1906.04043);
    - GLTR Test 2 Features (Rank Counting) [[Ref]](https://arxiv.org/abs/1906.04043);
- Model-based methods:
    - OpenAI-D [[Ref]](https://arxiv.org/abs/1908.09203);
    - ChatGPT-D [[Ref]](https://arxiv.org/abs/2301.07597);
    - MPU [[Ref]](https://arxiv.org/abs/2305.18149);

## Supported Datasets
- Essay;
- Reuters; 
- SQuAD1;

## Installation
```
conda env create -f environment.yml;
conda activate Detection;
mkdir save_models
download gpt2-medium model from https://huggingface.co/openai-community/gpt2-medium, and move it to save_models/
download chatgpt-detector-roberta model from https://huggingface.co/Hello-SimpleAI/chatgpt-detector-roberta, and move it to save_models/
download roberta-base-openai-detector model from https://huggingface.co/openai-community/roberta-base-openai-detector, and move it to save_models/
download AIGC_detector_env2 model from https://huggingface.co/yuchuantian/AIGC_detector_env2, and move it to save_models/
```

## Train
```
usage: python benchmark.py --finetune [--method METHOD] [--dataset DATA_NAME] [--detectLLM TEST_TEXT]
               [--conf_threshold CONF_THRESHOLD] [--filter_threshold FILTER_THRESHOLD]
               [--sentence_num SENTENCE_NUM]

optional arguments:
  --method METHOD
                        Supported: Log-Likelihood, Rank, Log-Rank, Entropy, GLTR, ChatGPT-D, OpenAI-D, MPU, ChatGPT-STK, OpenAI-STK, MPU-STK
  --dataset DATA_NAME
                        Supported: Essay, Reuters, and SQuAD1.
  --detectLLM TEST_TEXT
                        Supported: 
                          Essay: ChatGPT-turbo, ChatGLM, Dolly, ChatGPT, GPT4All, Claude;
                          Reuters: ChatGPT-turbo, ChatGLM, Dolly, ChatGPT, GPT4All, Claude;
                          SQuAD1: ChatGPT-turbo, ChatGLM, Dolly, ChatGPT, GPT4All, StableLM.
  --conf_threshold CONF_THRESHOLD
                        E-step detection threshold $r_e$.
  --filter_threshold FILTER_THRESHOLD
                        Filter ratio $\tau$.
  --sentence_num SENTENCE_NUM
                        Sentence number per sequence.
```

## Test
```
usage: python benchmark.py [--method METHOD] [--dataset DATA_NAME] [--detectLLM TEST_TEXT]
               [--conf_threshold CONF_THRESHOLD] [--filter_threshold FILTER_THRESHOLD]
               [--sentence_num SENTENCE_NUM] [--load_path LOAD_PATH]

optional arguments:
  --method METHOD
                        Supported: Log-Likelihood, Rank, Log-Rank, Entropy, GLTR, ChatGPT-D, OpenAI-D, MPU, ChatGPT-STK, OpenAI-STK, MPU-STK
  --dataset DATA_NAME
                        Supported: Essay, Reuters, and SQuAD1.
  --detectLLM TEST_TEXT
                        Supported: 
                          Essay: ChatGPT-turbo, ChatGLM, Dolly, ChatGPT, GPT4All, Claude;
                          Reuters: ChatGPT-turbo, ChatGLM, Dolly, ChatGPT, GPT4All, Claude;
                          SQuAD1: ChatGPT-turbo, ChatGLM, Dolly, ChatGPT, GPT4All, StableLM.
  --conf_threshold CONF_THRESHOLD
                        E-step detection threshold $r_e$.
  --filter_threshold FILTER_THRESHOLD
                        Filter ratio $\tau$.
  --sentence_num SENTENCE_NUM
                        Sentence number per sequence.
  --load_path LOAD_PATH
                        The address where the training model is loaded. The format is “Dataset-LLM“. 
                        For example, Essay-ChatGPT means the detector is trained on Essay based on the text generated by ChatGPT.
